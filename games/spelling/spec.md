# 英文單字拼圖（Spelling Tiles）網頁版規格

共通要求（產品原則、大廳整合介面、遊戲流程、交通工具上的操作、暫停與計時、統計、本機儲存、PWA 與離線、相容性、部署與共用驗收）依 [`games/spec.md`](../spec.md)。本文件只寫英文單字拼圖特有的內容，以及對共用規格的補充與例外。

## 產品範圍

- 目錄名稱 `spelling`（部署網址 `/spelling/`，localStorage 前綴 `spelling.`，快取前綴 `spelling-`），大廳顯示名稱「英文單字拼圖」。
- **學習遊戲**：列在大廳「獎勵遊戲」，過關寫入 `games.rewards`（見共用規格「跨遊戲獎勵紀錄」）。
- 玩法：畫面顯示一個單字的中文意思與詞性，下方是打亂的字母方塊；依序點字母方塊，把單字拼進上方的空格。一局 10 個單字。
- 詞庫：大考中心「高中英文參考詞彙表」（俗稱 7000 字，Level 1～6）。Level 1～2 約為國中程度，難度依 Level 區分，國中生到高中生都能使用。
- **核心價值：練習「看中文拼出英文」**。與「英文單字連線」（看英文選中文的配對）互補：連線練認字，拼圖練拼字。
- 每拼完一個單字顯示單字卡（英文、發音、詞性、中文、例句與翻譯），並以「單字本」記錄每個 Level 的學習進度與待複習的單字。
- 不在本版範圍：
  - 片語與多字詞組。
  - 音標顯示、聽寫（只聽發音拼字）、自訂單字清單、與他人比賽。
  - 英式拼寫：詞彙表並列英美拼寫時一律採美式。

## 共用規格的例外

- **發音**（例外：共用規格「不播放任何聲音」）：拼字要聽得到單字怎麼念，所以提供發音。語音的選擇、iOS 相容與靜音提示，做法與「英文單字連線」相同（見 [`games/words/spec.md`](../words/spec.md)「共用規格的例外」），可直接沿用其 `speech.js`。
  - 使用裝置內建的英文語音合成（Web Speech API），不下載音檔。裝置沒有英文語音時隱藏所有發音按鈕，不影響遊玩；離線時能否發音取決於裝置是否內建英文語音，在說明中告知。
  - **出題區的發音按鈕**：點按念出本題單字，幫助邊聽邊拼。
    - 不扣提示，也不影響「已學會」與「全對」的判定。
    - 不自動播放：要不要先聽，由玩家決定。
  - **單字卡的發音按鈕**：念出單字；例句旁另有按鈕念出整句例句。
  - **拼對後自動發音**：拼對時自動念一次單字，加深「拼法對應讀音」的印象。
    - 這是本遊戲唯一會自動發出聲音的時機，由玩家的最後一次點按觸發。
    - 設定中可以關閉，預設開啟。
  - 設定：
    - 發音（開／關）：關閉時隱藏所有發音按鈕，也不自動發音。
    - 拼對後自動發音（開／關）。
    - 語音（自選後試聽一次）。
    - 語速（正常、慢速）。
  - 除了上述情況，不發出任何聲音（沒有音效或背景音樂）。
- **不使用 Web Worker 出題**：本遊戲的出題是從詞庫選 10 個單字並打亂字母，在主程式 50 毫秒內完成，不需要 Web Worker 與預先產生（`.pregen`），與「英文單字連線」相同。
- **不採用共用規格的「邏輯技巧分級」**：難度由單字的 Level 與干擾字母數量決定（見「難度與出題」）。共用規格中「答案唯一」的精神仍然適用，見「答案唯一」。

## 規則

- 一局 10 個單字，依序作答；全部拼完即過關。
- 每個單字顯示中文意思、詞性與字母數（以空格數表示）。
- 字母方塊包含這個單字的所有字母（重複的字母各一塊），困難與專家另外加入干擾字母。
- 點字母方塊，字母填入第一個空格；全部填滿時自動判定：
  - **拼對**：空格變為完成色，顯示單字卡，按「下一個」繼續。
  - **拼錯**：位置正確的字母變綠並鎖定，位置錯誤的字母標紅並加 ✕，0.8 秒後退回字母方塊區。錯誤次數 +1。
- 單字中的空格、連字號、撇號（例如 *o'clock* 的撇號）預先填好，不需要拼。
- 答錯不結束遊戲，不設錯誤次數上限（依共用規格）。

## 遊戲流程

依共用規格，另外補充：

- 首頁點 Level 1～6 的卡片（或「待複習」），再選難度開始。難度清單把該 Level 推薦的難度排第一並標示「推薦」（見「難度與出題」）。
- 一局中途離開，回來時停在同一個單字，已鎖定的字母、錯誤次數、提示餘額與耗時都保留。
- 完成畫面：依共用規格顯示難度、耗時、錯誤次數、已用提示與最佳紀錄。另外列出本局的 10 個單字，答錯或用過提示的單字標示「待複習」，點了可開啟單字卡。

## 畫面與操作

- 由上而下：
  1. 頂部列：範圍、難度、進度（例如「3 / 10」）、耗時、錯誤次數、暫停。
  2. 題目區：中文意思（大字）、詞性、發音按鈕（見「共用規格的例外 › 發音」），下方是**挖空的例句**（該單字換成「＿＿＿」）作為上下文線索，幫助區分功能詞（*of*、*to*）、多義字與同義字；拼對後顯示完整例句。
  3. 答案空格。
  4. 字母方塊區。
  5. 工具列：退格、清除、提示。
- 版面尺寸（手機直向 375 CSS px 寬，不縮放）：
  - 答案空格寬至少 28 CSS px；超過 10 個字母時換成兩行。
  - 字母方塊 44 × 44 CSS px 以上，每行最多 7 個，最多 3 行。
  - 不得出現水平捲動。
- **只用點按，不使用拖曳**（晃動的交通工具上拖曳容易失手）：
  - 點字母方塊：填入第一個空格，方塊變成空位（保留原位置，避免其他方塊移動造成誤點）。
  - 點已填入的字母：退回原本的方塊位置，空格變空（已鎖定的綠色字母不能退回）。
  - 退格：退回最後填入的字母。清除：退回所有未鎖定的字母。
- **提示**：
  - 填入下一個尚未鎖定的正確字母並鎖定（標示提示記號），扣 1 次。
  - 位置上已有錯誤的字母時，先把它退回字母方塊區。
  - 用了提示的單字列入「待複習」。
- **桌面鍵盤**：
  - 輸入英文字母：選取第一個尚未使用、相同字母的方塊；沒有這個字母時短暫提示「沒有這個字母」。
  - Backspace：退格。Delete：清除。
  - Enter：拼完後前往下一個。
  - S 念出本題單字（發音可用時）。
  - H 提示，P 或 Esc 暫停；N 與 Ctrl／⌘＋Z 不使用（依共用快捷鍵規則忽略）。
  - H、P、S 也是字母：字母方塊中還有這個字母時當作輸入，沒有時才當作快捷鍵；按 Shift＋H／P／S 一律當作快捷鍵。
- 暫停時遮住題目、空格與字母方塊。
- 復原：以退格與點已填入的字母取代，不另外提供。

## 難度與出題

| 難度（代碼） | 推薦給 | 干擾字母 | 首字母 | 每局提示額度 |
| --- | --- | ---: | --- | ---: |
| 簡單（`easy`） | Level 1 | 0 | 預先填好並鎖定 | 6 次 |
| 中等（`medium`） | Level 2 | 0 | 不提供 | 5 次 |
| 困難（`hard`） | Level 3～4 | 2 | 不提供 | 4 次 |
| 專家（`expert`） | Level 5～6 | 3 | 不提供 | 3 次 |

- 任何 Level 都可以選任何難度（例如用專家難度練 Level 2）；統計依難度計算，符合大廳讀取格式。
- 單字長度：簡單 3～7 個字母，中等 3～9 個，困難與專家不限。長度只計需要拼的字母。該範圍符合長度的單字不足 10 個時，放寬長度並在開始前提示。
- 干擾字母：
  - 從 a～z 隨機挑選，不使用 q、x、z、j。
  - 不與單字中出現的字母重複。
  - 不得讓字母方塊拼得出「答案唯一」所禁止的單字。
- 選字順序：
  1. 優先出範圍內**尚未學會**的單字，其次為「待複習」與較久沒出現的單字。
  2. 同一局不重複。
  3. 不得與最近 50 個出過的單字（`spelling.recent`）重複；範圍內單字不足時放寬。
- 字母打亂後不得與答案順序相同，也不得與答案的前半部完全相同（避免直接照抄）。
- 「待複習」範圍只出待複習的單字；不足 10 個時，以同 Level 未學會的單字補足。

### 答案唯一

- 「中文意思相同」指 `zh` 以「、」分隔的意思中至少一項完全相同；「詞性相同」指 `pos` 以「/」分隔的詞性中至少一項相同。
- 判定以本題單字為準。玩家拼出詞庫中**中文意思與詞性都相同**的另一個單字（例如本題 *big*，字母方塊剛好拼得出 *large*），也算拼對，單字卡顯示兩者。
- 出題時須避免：字母方塊拼得出詞庫中中文意思相同、但詞性不同的單字（例如名詞與動詞同義）。
- 同一局不出現中文意思相同的兩個單字。

## 詞庫

### 來源與範圍

- 單字清單取自大考中心「高中英文參考詞彙表」，以大考中心公告的最新版本為準。
- 採用版本：111 學年度起適用（民國 109 年 7 月公告，6 級共約 6,000 詞條；「7000 字」是舊版的俗稱）。
- 原始檔為 `data/ceec/ceec-108.json`（從 PDF「依級別排序」擷取），`data/README.md` 記錄版本、下載網址、下載日期與使用條款。
- **授權**：詞彙表註明「著作權屬財團法人大學入學考試中心基金會所有，僅供非營利目的使用，轉載請註明出處」。因此 `data/ceec/` 與由它整理出的英文單字、詞性與 Level **不適用本專案的 Apache License 2.0**，在根目錄 `NOTICE` 與 `data/README.md` 另行標示；遊戲「玩法」與首頁註明出處。
- 只取用詞彙表的**英文單字、詞性與 Level**。中文意思、例句與翻譯一律**原創撰寫**，不得複製字典、教材、詞彙表附註或出版品的內容。
- 整理規則：
  - 詞彙表並列多種寫法時：
    - 只差 1 個字母、或等長且只差 2 個字母的拼寫變體（例如 *toward*／*towards*、*judgment*／*judgement*、*disk*／*disc*）只取第一種寫法。
    - 不同的字（例如 *airplane*／*plane*、*prince*／*princess*、*ad*／*advertisement*）分成多個單字，各自標同一 Level。
    - 只差重音或大小寫（*café*／*cafe*、*Internet*／*internet*）取不含重音的小寫寫法。
  - 括號：*agree(ment)* 收 *agree* 與 *agreement* 兩個字（詞性依括號內外分開）；*glove(s)* 只收單數。
  - 代名詞 *he (him, his, himself)* 只收主格。
  - 同一個字在不同詞條重複出現時，詞性不同才另收一筆（`id` 加 `-2`）。
  - 一個單字有多個詞性時合併為一筆，詞性以「n./v.」表示，中文取最常用的 1～2 個意思。
  - 排除（寫入 `data/excluded.json` 並附原因）：
    - 只有 1 個字母的單字（*a*、*I*）。
    - 含句點的縮寫與全大寫縮寫（*a.m.*、*Mrs.*、*TV*）。
    - 含大寫字母的專有名詞（*Celsius*、*T-shirt*）。
- 數量：整理後共 6,123 個單字（Level 1～6：1,015／1,035／1,015／1,025／1,007／1,026），排除 60 筆。

### 資料格式

- 撰寫批次為 `data/batches/level-<n>-<批次>.json`，初稿為 `data/draft/`，審閱後定稿為 `data/words/level-<n>-<批次>.json`；以 `npm run words` 合併已審閱的單字，依 Level 輸出 `src/data/level-<1～6>.json`（陣列的陣列，節省空間）。
- 啟動時同時載入 6 個 Level 的檔案（全部列入 Service Worker 預先快取，離線可用）。
- 詞庫總大小不超過 2 MB（未壓縮）。
- 每個單字包含：

  | 欄位 | 說明 |
  | --- | --- |
  | `id` | 穩定的識別碼，一經發布不得更改（單字本以此記錄進度）；規則與「英文單字連線」相同（英文轉小寫、以連字號連接） |
  | `en` | 英文單字（美式拼寫） |
  | `pos` | 詞性：n.、v.、adj.、adv.、prep.、conj.、pron.、aux.、int. 等，多個詞性以「/」連接 |
  | `level` | 1～6，與詞彙表一致 |
  | `zh` | 中文意思：台灣用語與繁體中文，12 字以內，取最常用的 1～2 個意思 |
  | `example` | 例句（英文，15 個單字以內，須包含該單字，可為變化形） |
  | `form` | 例句中該單字的實際字形（變化形時填寫，原形時為空字串） |
  | `exampleZh` | 例句的中文翻譯 |
  | `reviewed` | 是否已通過審閱；只有 `true` 的單字會出題 |

- 例句盡量只用同 Level 或更低 Level 的單字，題材以校園、家庭、旅行與日常生活為主，避免政治、宗教、暴力與歧視性題材。
- 可以參考「英文單字連線」詞庫中相同單字的中文意思與例句，但收錄到本遊戲時仍須重新審閱。兩個遊戲的詞庫各自獨立，不共用檔案。

### 品質把關

- 依「英文單字連線」的做法：撰寫 agent 產生初稿，**另一個獨立的審閱 agent** 逐筆檢查，通過後才標記 `reviewed`。
- 每個批次審閱完成後產生審閱紀錄 `data/reviews/level-<n>-<批次>.md`，列出檢查數量、通過數，以及修正的單字、原本內容、修改內容與原因。
- 撰寫與審閱規範見 `data/AUTHORING.md`；例句挖空後要能從上下文猜出單字，例句的意思與 `zh` 的第一個意思一致；清單中涉及宗教、政治、死亡或性別的字照樣收錄，例句寫成中性、知識性的情境。
- 審閱 agent 對每個單字檢查：
  - 中文意思是否正確、是否為台灣用語、是否為最常用的意思。
  - 詞性與 Level 是否與詞彙表一致。
  - 同義群組是否完整。
  - 例句文法、是否自然、是否用到這個意思；例句翻譯是否正確；是否符合題材限制。
- 自動化驗證（`npm test`）：
  - `id`、`en` 不重複；`en` 只含英文字母、空格、連字號與撇號，長度至少 2。
  - `id`、`en`、`pos`、`level` 與 `data/list.json` 一致；`data/list.json` 與整理規則的輸出一致。
  - `zh` 不為空、不超過 12 字，不含英文、括號或逗號。
  - 每個定稿檔都有審閱紀錄。
  - 同義字不另外標記：遊戲依中文意思自動判斷（見「答案唯一」）。
  - `example` 包含 `en` 或 `form`；`exampleZh` 不為空。
  - 詞庫總大小不超過 2 MB。

## 統計

- 依共用規格（`spelling.stats`，以難度代碼為鍵；`noHint` 為沒用提示完成的局數）。
- 單字本另外記錄每個單字的學習狀態，見「單字卡與單字本」。

## 單字卡與單字本

- **單字卡**：
  - 內容：英文（大字）與發音按鈕、詞性、Level、中文意思、例句（旁邊有例句發音按鈕）與翻譯，例句中的該單字以粗體標示。
  - 每拼完一個單字顯示一次；完成畫面可再次查看。
  - 單字卡文字可以選取複製。
- **單字本**：
  - 從首頁進入，顯示「已學會 N / 詞庫總數」，以及 Level 1～6 各自的進度（例如「Level 2 已學會 312 / 1,000」）。
  - 已學會：至少一次沒有拼錯、也沒用提示就拼對的單字。
  - 待複習：拼錯或用了提示的單字；之後一次沒錯、沒用提示就拼對，即移出待複習。
  - 可依 Level 篩選，以英文或中文搜尋；點單字顯示單字卡。

## 跨遊戲獎勵紀錄

依共用規格「跨遊戲獎勵紀錄」，照抄學習遊戲（例如 `games/idiom/src/js/storage.js`）的 `addReward()` 與 `dailyId()`：

- 每個難度第一次過關寫入 `spelling:<難度代碼>:clear`。
- 第一次沒用提示過關寫入 `spelling:<難度代碼>:perfect`（禮包等級 +1）。
- 每次過關都寫入每日練習 `daily:YYYY-MM-DD`。
- 範圍（Level）不影響禮包等級，以難度為準。

| 鍵 | 內容 |

| `spelling.save` | 目前一局：範圍、難度、10 個單字 id、每題的字母方塊（含干擾字母）與順序、已填入與已鎖定的字母、提示記號、目前題號、錯誤次數、已用提示、耗時；欄位符合大廳讀取格式（`difficulty`、`elapsedMs`、`completed`） |
| `spelling.stats` | 共用格式（`easy`、`medium`、`hard`、`expert`） |
| `spelling.book` | 單字本：以單字 `id` 為鍵，記錄出現次數、拼對次數、是否已學會、是否待複習、最後出現時間 |
| `spelling.recent` | 最近 50 個出過的單字 id |
| `spelling.settings` | 發音開關、拼對後自動發音開關、語音、語速、主題 |

- 存檔只記錄單字 `id`，讀取時從詞庫取回內容；詞庫更新後找不到的 `id` 依「資料損毀」處理該局，單字本中找不到的 `id` 直接略過。
- 依共用規格「遊玩歷程與帳號凍結」放入共用模組 `src/js/playlog.js`（從大廳 `src/playlog.js` 複製，不得修改）。

## 外觀

- 遊戲主色：**葡萄紫到桃紅**的漸層（`--brand-1: #7c5cf0`、`--brand-2: #d9468f`），與現有遊戲區隔。上架時大廳卡片使用相同的漸層。
- 字母方塊做成拼圖片的樣子：圓角方塊，帶淡淡的立體陰影，字母以等寬大寫粗體顯示。
- 空格狀態：
  - 未填：虛線底。
  - 已填：實線框。
  - 鎖定：綠底加 ✓。
  - 提示：加上燈泡小記號。
  - 錯誤：紅底加 ✕。
- 錯誤與提示的語意色不得被主色取代；拼對時的效果短暫、單次，並尊重「減少動態效果」設定。
- 其餘依共用規格的豐富色調要求。

## 驗收條件

除共用驗收條件外：

1. 詞庫驗證測試全部通過。首次上架時：
   - Level 1～2 全部已審閱，Level 3～6 每級至少 300 個已審閱。
   - 每個已上架的 Level 都有審閱紀錄。
   - 由審閱 agent 以外的檢查，每個 Level 隨機抽查 50 個單字（中文意思、詞性、例句），錯誤少於 1 個。
2. 批次驗收（`npm run check:puzzles`）：每個難度 × 每個 Level 各產生 100 局，全部合格，每局在 50 毫秒內完成。合格條件：
   - 每局 10 個不重複的單字，不含中文意思相同的兩個單字。
   - 字母方塊恰好包含答案的字母，加上該難度數量的干擾字母。
   - 干擾字母不在答案中，打亂後不等於答案。
   - 字母方塊拼不出中文意思相同、但詞性不同的其他單字。
3. 拼字操作：
   - 點方塊填入第一個空格；點已填入的字母退回原位。
   - 退格、清除不影響已鎖定的字母。
   - 拼錯時位置正確的字母鎖定、錯誤的退回並計錯誤一次。
   - 拼出中文意思與詞性都相同的其他單字算拼對。
4. 提示填入並鎖定下一個正確字母、扣次數；用完後停用並說明。簡單難度的首字母預先填好且不扣提示。
5. 單字本：「已學會」「待複習」的判定與移出正確；各 Level 進度正確；搜尋與篩選正確。
6. 獎勵：第一次過關、第一次全對、每日練習依「跨遊戲獎勵紀錄」寫入 `games.rewards`；重複過關不再寫入。
7. 手機直向 375 CSS px 寬時：
   - 12 個字母的單字加 3 個干擾字母，空格與字母方塊完整顯示，不需捲動。
   - 單手可以完成所有操作。
8. 桌面可只用鍵盤完成一局（輸入字母、Backspace、Enter、H、P），另外按 S 念出本題單字。
9. 發音：
   - 出題區、單字卡的單字與例句按鈕都能念出正確內容。
   - 使用出題區的發音不扣提示，也不影響「全對」。
   - 「拼對後自動發音」開啟時，拼對自動念一次；關閉時不念。
   - 關閉「發音」後，所有發音按鈕隱藏，也不自動發音。
   - 裝置沒有英文語音時，按鈕隱藏且遊戲正常。
   - 除此之外不發出任何聲音。
10. 重新整理或在背景被系統結束後再開啟，範圍、難度、題號、已填與已鎖定的字母、錯誤次數、提示餘額與耗時都與最後一次操作一致。
11. 遊玩歷程與帳號凍結：
    - 遊玩超過 10 秒後，大廳「遊戲歷程」出現「英文單字拼圖」。
    - 凍結時本遊戲被凍結畫面蓋住。

## 開發順序

1. **詞庫來源**：取得大考中心詞彙表，確認使用條款並標示授權，整理為 `data/ceec/`；寫好資料格式與驗證測試。
2. **詞庫內容**：撰寫 agent 依 Level 分批產生中文意思與例句，審閱 agent 逐筆審閱。先完成 Level 1～2 全部與 Level 3～6 每級 300 個。
3. **出題器**：選字、打亂、干擾字母、答案唯一檢查；批次驗收腳本 `npm run check:puzzles`。
4. **遊戲畫面**：題目區、空格、字母方塊、退格、清除、提示、錯誤回饋、單字卡、完成畫面。
5. **單字本、首頁範圍選擇與統計**。
6. **發音**：沿用「英文單字連線」的 `speech.js`，完成出題區、單字卡與例句的發音按鈕、拼對後自動發音與設定。
7. **共用整合**：`playlog.js`、`games.rewards`、「‹ 所有遊戲」、豐富色調、PWA、離線與更新流程。
8. **上架到大廳**：依共用規格「上架到大廳」完成並驗收。學習遊戲另外：
   - `src/portal.js` 的 `GAMES` 加上 `reward: true`。
   - 口袋地城 `GIFT.games` 加上 `spelling: '英文單字拼圖'`，並加入 `GIFT.learning`。
9. **持續擴充**：分批補完 Level 3～6，每批都須經審閱 agent 審閱並通過驗證。
