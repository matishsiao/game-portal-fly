# 社會科學：用語對照表

題目、提示、詳解與知識卡一律使用「使用」欄的寫法；「不使用」欄的寫法由 `npm test` 與 `npm run validate` 自動檢查（`scripts/bank-rules.mjs` 的 `BANNED` 須與本表一致）。原則見 [`spec.md`](../spec.md)「內容原則：中立與正確」。

> **狀態：使用者已確認（2026-10-28）。** 本表依 108 課綱與現行國中小教科書的通用寫法整理；新增或修改用語時，先請使用者確認再寫入。
