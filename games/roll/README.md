# 滾滾解謎

可離線遊玩的物理邏輯解謎 PWA，屬於「遊戲大廳」的一款遊戲。規格見 [spec.md](spec.md)，共通要求見 [`games/spec.md`](../spec.md)。

## 指令

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 開發模式，提供 `src/`，不啟用 Service Worker |
| `npm run levels` | 把 `levels/*.txt` 合併為 `src/js/levels-data.js`（含每關最少步數） |
| `npm run build` | 合併關卡並建置到 `dist/` |
| `npm run preview` | 建置並以 `dist/` 啟動，啟用 Service Worker |
| `npm test` | 規則引擎、解題器、星等與解鎖的單元測試 |
| `npm run check:levels` | 驗證全部 80 關可過關，列出每關最少步數與狀態數 |
| `npm run icons` | 重新產生圖示 |

## 規則（回合制、格子化的物理）

每次操作後依固定順序結算，直到盤面靜止：

1. 滾滾移動或推動物件（一次只能推一個；冰塊被推後一直滑，直到受阻或下方懸空）。
2. 氣球往上飄，帶著上方的滾滾或木箱一起上升；上面壓著石塊時不會上升。
3. 浮在水中的木箱、冰塊浮到水面。
4. 由下往上處理掉落：木箱、冰塊落入水中即停在水面；石塊沉到水底；石塊從 2 格以上掉到易碎磚上時把它壓碎。
5. 盤面靜止後，停在彈簧上的滾滾被往上彈 3 格並懸停，等待下一步往左右跳。
6. 滾滾位於旗子即過關；掉進水裡即失敗（須復原或重新開始）。

規則的精確定義以 `src/js/engine.js` 與 `tests/engine.test.mjs` 為準；修改規則後須執行 `npm run levels` 與 `npm run check:levels` 重新驗證所有關卡。

## 關卡檔格式

`levels/<章節>-<編號>.txt`：

```
title: 推箱子填坑
hint: 走向木箱就能推動它；把木箱推進坑裡，就能走過去。

########
#@.B..*#
####.###
########
```

| 字元 | 意義 | 字元 | 意義 |
| --- | --- | --- | --- |
| `#` | 牆 | `@` | 滾滾 |
| `.` | 空氣 | `B` | 木箱 |
| `H` | 梯子 | `S` | 石塊 |
| `~` | 水 | `I` | 冰塊 |
| `*` | 終點旗子 | `o` | 氣球 |
| `x` | 易碎磚 | `b`／`i` | 一開始就浮在水中的木箱／冰塊 |
| `^` | 彈簧 | | |

- 盤面寬 6～10、高 4～12，四周須為牆，恰好一個終點。
- 關卡 id 一經發布不得更改；新增關卡只能加在章節末尾或新增章節。
- `scripts/generate-levels.mjs` 是設計輔助：隨機產生候選盤面，以解題器篩選「可過關、物件不可或缺、用到本章機制」的關卡並自動精簡，依難度輸出供挑選。各章前幾關（介紹新物件）為手工設計。

## 原創聲明

本遊戲的玩法概念參考「以物理特性解謎」的遊戲類型；名稱、角色、美術、文字與所有關卡皆為原創，未使用 Thinkrolls 的名稱、角色、圖像或關卡配置。
