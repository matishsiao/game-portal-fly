# 奧數挑戰（Math Olympiad）網頁版規格

共通要求（產品原則、大廳整合介面、遊戲流程、交通工具上的操作、暫停與計時、統計、本機儲存、PWA 與離線、相容性、部署與共用驗收）依 [`games/spec.md`](../spec.md)。本文件只寫奧數挑戰特有的內容，以及對共用規格的補充與例外。

## 產品範圍

- 目錄名稱 `olympiad`（部署網址 `/olympiad/`，localStorage 前綴 `olympiad.`，快取前綴 `olympiad-`），大廳顯示名稱「奧數挑戰」。
- 對象：國小學童（小一～小六），家長可在搭機、搭車時交給小朋友單獨遊玩。
- **學習遊戲**（大廳列在「獎勵遊戲」）：依共用規格「跨遊戲獎勵紀錄」寫入 `games.rewards`（見「獎勵禮包」）；並依共用規格「遊玩歷程與帳號凍結」使用 `src/js/playlog.js`。
- 玩法：每局 10 題奧林匹克數學（奧數）選擇題，每題 4 個選項，點選作答。
- **核心價值：答錯時引導思考，不直接給答案。** 答錯時顯示這一題的「解題重點」，讓小朋友依提示自己想出正解；答對後才顯示完整詳解。
- 產品特性：
  - 只用點選作答，不需要輸入文字或數字，離線、單手也能玩。
  - 四級難度對應年級，涵蓋找規律、巧算、植樹、雞兔同籠、年齡、和差、計數、邏輯推理、週期、容斥、抽屜原理、行程、數字謎、幾何等奧數題型。
  - 題目來源分兩種：人工設計並經獨立審題的「固定題庫」，以及「題型模板」（同一題型換數字產生新題目，答案由程式計算），讓小朋友玩很多局也不會一直遇到相同題目。
  - 「錯題本」列出答錯或看過解題重點的題目，供複習；模板題答錯時，之後會用同一題型換數字再出題。
  - 護眼配色與休息提醒，讓小朋友長時間遊玩眼睛也不容易疲勞（見「外觀」）。
  - 第一次過關與第一次全對可獲得口袋地城的獎勵禮包（見「獎勵禮包」）。
- 題目全部為本專案原創，不轉載競賽試題或出版品內容。
- 不在本版範圍：需要圖形才能作答的題目（本版題目只用文字描述）、填空題、計分排行、自訂題庫、語音朗讀、家長報表。

## 共用規格的例外

- **以固定題庫加題型模板取代出題器**（共用規格「出題」一節的例外）：奧數題目需要人工設計題意、誘答選項與解題重點，無法整題由程式自由產生；只有「換數字就是新題目」的題型以人工設計的模板產生數字。因此：
  - 題目來自隨遊戲散布的固定題庫 `src/data/questions.json` 與題型模板 `src/js/olympiad/templates.js`，運算量極小，不需要 Web Worker、預先產生（`.pregen`）與逾時處理；開新局須在 100 毫秒內完成。
  - 「唯一解」改為「恰好一個正確選項」，以「題庫驗證」與「模板驗證」的自動化檢查及獨立審題保證。
  - 「最近 50 題不重複」改以「題目紀錄」的挑題規則取代（見「難度與挑題」）。
  - `npm run check:puzzles` 改為執行題庫與模板檢查（`scripts/check-bank.mjs`），沿用同一個指令名稱讓大廳統一呼叫。
- **不採用「邏輯技巧分級」**：難度依題型與目標年級由出題者決定，並經獨立審題確認（見「題庫驗證」）。
- **「全對」加嚴**：共用規格以「沒用提示」判定全對；本遊戲另要求整局沒有答錯（答錯會自動顯示解題重點，等同看了提示）。`.stats` 的 `noHint` 只在「沒有答錯且沒有主動看解題重點」時累加。
- **不提供復原與筆記**：選擇題作答後立即判定，沒有可復原的操作；按 N、Ctrl／⌘＋Z 時忽略。

## 規則

- 每題有 4 個選項，恰好一個正確。
- 點選選項即作答，立即判定對錯：
  - **答對**：該題完成，顯示「答對了！」與詳解，按「下一題」繼續。
  - **答錯**：該選項標示紅色加 ✕ 並停用，錯誤次數 ＋1，顯示解題重點（見下方），小朋友繼續從剩下的選項作答。
- 答錯不結束遊戲；每題一定要答對才能進入下一題。
- 10 題全部答對，該局即完成。

## 解題重點

- 每題有 2 段解題重點（`keys[0]`、`keys[1]`），由淺到深引導，**都不得寫出答案或直接指出哪個選項正確**。
- 顯示時機：每次答錯都顯示下一段尚未顯示的解題重點（先前的保留在上方）：
  - 第 1 次答錯：顯示第 1 段（若已主動看過第 1 段，則顯示第 2 段）。
  - 第 2 次答錯：顯示第 2 段。
  - 第 3 次答錯：只剩一個選項，另顯示「只剩下一個選項了，想一想它為什麼是對的，再點點看。」；仍不自動作答、不標示正解。
- 主動查看：作答前可按「解題重點」按鈕，依序顯示下一段（算一次提示）。每局額度依難度（見「難度與挑題」）；答錯自動顯示的不扣額度。
- 題目、解題重點與詳解在上方的作答區內捲動，選項固定在作答區下方，內容再長也不得把選項推出畫面；新出現的解題重點或詳解自動捲進可見範圍。
- 答對後的「詳解」（`explain`）才寫出完整算式與答案。

## 遊戲流程

依共用規格，另補充：

- 首頁的難度按鈕顯示難度名稱與建議年級（例如「初級」「小一～小二」兩行）。
- 遊戲畫面持續顯示：題號進度（例如「3 / 10」）、耗時、錯誤次數、剩餘「解題重點」次數。
- 已完成的題目不能回頭修改。
- 完成畫面：依共用規格顯示難度、耗時、錯誤次數、已用提示次數與最佳紀錄；另列出本局 10 題，每題標示「✓ 一次答對」「✕ 答錯 N 次」或「看了解題重點」，點選可展開題目、詳解與解題重點。
- 「重開本局」：保留同一組 10 題（選項順序不變），作答紀錄、耗時、錯誤次數與提示額度回到新局狀態。

## 畫面與操作

- 手機直向時，由上而下為：頂部列（題號、耗時、錯誤次數、暫停）、題目、解題重點區、4 個選項、工具列（「解題重點」按鈕）。
- 題目字級至少 18 CSS px，數學符號使用全形（＋、－、×、÷、＝）以利閱讀；題目較長時在題目區內捲動。
- 選項以「A」「B」「C」「D」標示，每個選項按鈕至少 44 CSS px 高、寬度佔滿版面；選項順序每局隨機排列，存檔後固定。
- 答對以綠色加 ✓ 標示該選項；答錯以紅色加 ✕ 並加刪除線標示；顏色之外都有文字或符號。答對後只留下正確選項與「下一題」，讓出空間顯示詳解。
- 回饋文字使用鼓勵語氣，例如答錯時「再想一想！看看下面的解題重點」，不使用「笨」「錯了吧」等負面字眼。
- 桌面鍵盤：數字鍵 1～4 或字母鍵 A～D 選擇選項；Enter 在詳解畫面等同「下一題」；共用快捷鍵 H 查看解題重點、P 或 Esc 暫停；N、Ctrl／⌘＋Z 忽略。
- 暫停時遮住題目、解題重點、選項與詳解。

## 錯題本

- 從首頁進入。列出曾經「答錯」或「看過解題重點」、且之後尚未一次答對的題目（「待複習」）；之後在任何一局一次答對（沒答錯、沒看解題重點）即自動移出。
- 另顯示「已練習 N / 題庫總數」。
- 依難度分組列出；點選題目展開正確答案、解題重點與詳解（錯題本是複習用，可直接看答案）。
- 提供「清除錯題本」並須確認。

## 難度與挑題

| 難度（代碼） | 遊戲內名稱 | 建議年級 | 每局題數 | 每局「解題重點」額度 |
| --- | --- | --- | ---: | ---: |
| `easy` | 初級 | 小一～小二 | 10 | 5 次 |
| `medium` | 中級 | 小三～小四 | 10 | 4 次 |
| `hard` | 高級 | 小五～小六 | 10 | 3 次 |
| `expert` | 挑戰 | 高年級競賽 | 10 | 3 次 |

- 使用共用難度代碼；大廳顯示為「簡單」「中等」「困難」「專家」。
- 每局 10 題的組成：固定題庫 6 題、模板題 4 題；該難度的模板不足 4 個時，以固定題庫補足。同一個模板一局最多 1 題。
- 挑題規則（`src/js/olympiad/pick.js`，純函式，可測試）：
  1. 固定題庫：優先挑「從未出現過」的題目；不足時依序補「待複習」、再補「最久沒出現」的題目。
  2. 模板：優先挑「待複習」的模板，再挑「最久沒出現」的模板；每次以新的亂數參數產生，且不得與該模板最近 20 題的參數相同。
  3. 同一局中同一題型（`topic`）最多 3 題（固定題與模板題合計）；同一局不重複。
  4. 題目順序與選項順序隨機。
- 數量（上架前提）：
  - 固定題庫每個難度至少 100 題（10 局不重複），每個難度至少涵蓋 8 種題型。
  - 題型模板每個難度至少 4 個。

## 題庫

### 檔案格式

`src/data/questions.json`：

```json
{
  "v": 1,
  "questions": [
    {
      "id": "easy-001",
      "difficulty": "easy",
      "topic": "pattern",
      "question": "找規律：1、3、6、10、15、□，□ 裡應該填多少？",
      "choices": ["21", "20", "25", "22"],
      "answer": 0,
      "keys": ["第 1 段解題重點", "第 2 段解題重點"],
      "explain": "答對後顯示的詳解"
    }
  ]
}
```

| 欄位 | 說明 |
| --- | --- |
| `id` | `<難度代碼>-<三位數流水號>`，一經發布不得更改或重複使用（錯題本與題目紀錄以此記錄）；題目刪除後編號保留不用 |
| `difficulty` | 難度代碼 |
| `topic` | 題型代碼（見下表） |
| `question` | 題目，只用文字描述，不得依賴圖形 |
| `choices` | 4 個互不相同的選項，帶單位（例如「5 棵」） |
| `answer` | 正確選項在 `choices` 中的索引（0～3）；顯示時選項順序另行隨機 |
| `keys` | 恰好 2 段解題重點，由淺到深 |
| `explain` | 詳解，含完整算式與答案 |

- 題型代碼：`pattern` 找規律、`calc` 巧算、`tree` 植樹、`chicken` 雞兔同籠、`age` 年齡、`sumdiff` 和差倍、`count` 計數、`logic` 邏輯推理、`cycle` 週期、`overlap` 容斥、`pigeon` 抽屜原理、`travel` 行程、`work` 工程、`average` 平均、`digit` 數字謎、`remainder` 餘數、`geometry` 幾何。新增題型時先更新本表。
- 寫題原則：
  - 誘答選項取自常見錯誤（例如植樹問題的「段數」、年齡問題的「把倍數直接用在今年」），不放明顯不合理的數字。
  - 數字以心算或簡單直式可完成為限；`easy` 的題目與詳解只用加減與九九乘法，不出現有餘數的除法；`medium` 不出現分數。
  - 使用台灣國小教材用語（例如「公尺」「平方公分」「星期三」）。
  - 解題重點引導「怎麼想」（畫圖、假設、倒推、列表、配對），不寫出答案數字或「答案是」；第 2 段比第 1 段更具體，但仍留一步讓小朋友自己算。
- 資料大小：`questions.json` 壓縮前不超過 300 KB（隨 Service Worker 離線快取）。

### 題庫驗證

每一題上架前都須通過以下兩道檢查：

1. **自動化檢查**（`tests/bank.test.mjs` 與 `scripts/check-bank.mjs`）：
   - `id` 不重複且符合格式；`difficulty`、`topic` 為已定義代碼。
   - `choices` 恰好 4 個且互不相同；`answer` 為 0～3 的整數；`keys` 恰好 2 段且不為空。
   - `keys` 的任一段都不包含正確選項的完整文字（例如正解「5 棵」時，`keys` 不得出現「5 棵」）。
   - `explain` 包含正確選項的數字部分（確認詳解與答案一致）。
   - 可由程式計算的題目（計數、餘數、數列、整數解），在 `tests/answers.test.mjs` 以暴力列舉獨立算出答案，與 `answer` 比對。
   - 各難度題數與題型數達到上架要求（`check-bank.mjs` 印出各難度、各題型的題數）。
2. **獨立審題**：由另一位審題者（另一個 agent 或另一個人，不得是出題者本人）在**不看答案**的情況下解每一題，並檢查：
   - 自己算出的答案與 `answer` 相同，其他 3 個選項都錯；題意沒有第二種合理解讀。
   - 解題重點沒有洩題、確實有幫助；詳解計算正確。
   - 用語符合目標年級、題意完整（不靠圖也能理解）。
   - 審題發現問題時修改題目後重新審題；審題結果（日期、審題者、修改的題目）記錄在 commit 訊息中。

### 題型模板

適合「換數字就是新題目」的題型（例如雞兔同籠、植樹、星期週期、年齡、和差、行程、餘數）。模板寫在 `src/js/olympiad/templates.js` 的 `TEMPLATES`，每個模板：

| 欄位 | 說明 |
| --- | --- |
| 模板代碼 | `TEMPLATES` 的鍵，小寫英文與 `-`（例如 `chicken-legs`），一經發布不得更改 |
| `difficulty`、`topic` | 難度代碼、題型代碼（同固定題庫） |
| `params(rng)` | 以亂數產生候選參數（正整數陣列） |
| `valid(params)` | 參數是否合用（個數、範圍與題意限制）；產生題目時不合用就重抽，讀取存檔時不合用即回傳 `null` |
| `build(params)` | 依參數組成題目：`question`、`choices`、`keys`、`explain`，格式與固定題庫相同 |

- 模板題的 `id` 為 `<模板代碼>#<參數以 - 連接>`（例如 `chicken-legs#12-5`）；存檔只記錄 `id`，讀取時以 `questionFromId()` 重建；參數不合用（存檔被改過或模板調整範圍後的舊存檔）時依「資料損毀」處理。
- 題意寫清楚所有條件，不留第二種解讀（例如植樹寫明「路的一旁」與兩端種不種；不使用「圓周長」等尚未教過的用語）。
- 詳解的除法寫成課本格式「200 ÷ 7 ＝ 28 … 4」，再以文字說明意義。
- 參數範圍由模板限定，使所有可能的題目都符合該難度的數字與運算限制（見「寫題原則」）；會造成誘答與正解相同或題意不自然的參數組合一律重抽。
- 正解與誘答選項都由程式計算；誘答取自該題型的常見錯誤算法，不足時以正解附近的數補足。
- 解題重點與詳解為帶入數字的固定句型，同樣不得寫出答案。
- 目前的模板（每個難度 4 個）：

  | 難度 | 模板代碼 |
  | --- | --- |
  | `easy` | `queue-position`（從前面數、從後面數求總人數）、`sequence-add`（等差數列下一項）、`marble-sumdiff`（和差求較少的一方）、`age-gap`（幾年後年齡差） |
  | `medium` | `chicken-legs`（雞兔同籠求兔子隻數）、`tree-planting`（單邊植樹四種種法）、`weekday-cycle`（再過 N 天是星期幾）、`age-multiple`（幾年後是幾倍） |
  | `hard` | `score-quiz`（答對得分、答錯扣分求答對題數）、`tree-both-sides`（路兩旁植樹）、`chase`（追及）、`work-together`（兩人合作的工程） |
  | `expert` | `power-remainder`（連乘除以 5、7、9 的餘數）、`train-bridge`（火車過橋）、`remainder-min`（除以 3、5、7 的餘數求最小數）、`handshake`（兩兩握手或單循環賽） |

### 模板驗證

每個模板上架前都須通過：

1. **自動化檢查**（`tests/templates.test.mjs`）：每個模板以固定種子批次產生 2,000 題，每題：
   - 符合固定題庫的格式檢查（4 個不同選項、2 段解題重點不含正解、詳解含正解）。
   - 測試**只讀題目文字**，以暴力列舉或逐步模擬（與模板不同的算法）獨立算出答案，必須恰好一個解，且與正解選項相同。
   - 由 `id` 重建的題目與原題完全相同。
2. **獨立審題**：由出題者以外的審題者檢查模板的參數範圍與邊界情況、各種分支（例如植樹的四種種法）的題意與用語，並自行寫程式批次比對答案；審題結果記錄在 commit 訊息中。

## 統計

- 依共用規格（`started`、`completed`、`bestMs`、`totalMs`、`noHint`），`noHint` 依「共用規格的例外」加嚴。
- 另以 `olympiad.record` 記錄每題的作答結果，供挑題與錯題本使用；「重設統計」不清除錯題本（另提供「清除錯題本」並須確認）。

## 獎勵禮包

依共用規格「跨遊戲獎勵紀錄」，照抄現有遊戲 `storage.js` 的 `addReward()`：

| 時機 | `id` | `type` | `tier` |
| --- | --- | --- | ---: |
| 該難度第一次完成一局 | `olympiad:<難度代碼>:clear` | `clear` | `easy` 1／`medium` 2／`hard` 3／`expert` 4 |
| 該難度第一次全對（10 題都沒答錯、沒看解題重點） | `olympiad:<難度代碼>:perfect` | `perfect` | 過關等級 ＋1 |
| 每完成一局 | `daily:YYYY-MM-DD` | `daily` | 1 |

- 「第一次」以更新統計前的 `completed`、`noHint` 判斷。
- 使用共用 `.stats` 格式，口袋地城會自動從 `olympiad.stats` 補發上架前已完成的紀錄，不需另寫補發規則。
- 上架時：大廳 `src/portal.js` 的 `GAMES` 加上 `reward: true`（列在「獎勵遊戲」）；口袋地城 `GIFT.games` 註冊 `olympiad: '奧數挑戰'` 並加入 `GIFT.learning`。
- 完成畫面列出這次新得到的禮包（例如「🎁 獲得口袋地城獎勵：中等 第一次過關、今天的每日練習」）。

## 本機儲存

依共用規格，另外：

| 鍵 | 內容 |
| --- | --- |
| `olympiad.save` | 目前一局：`v`、`difficulty`、10 題的 `id` 與選項顯示順序、目前題號、每題已選過的選項、每題看過的解題重點段數、錯誤次數、已用提示、`elapsedMs`；欄位符合大廳讀取格式 |
| `olympiad.stats` | 共用格式（`easy`、`medium`、`hard`、`expert`） |
| `olympiad.record` | 固定題以題目 `id` 為鍵、模板題以模板代碼為鍵：出現次數、最後出現時間、是否待複習；模板另記最近 20 題的參數與最後一次答錯的題目 `id`（錯題本顯示這一題） |
| `olympiad.settings` | 主題設定、休息提醒開關 |

- 存檔只記錄題目 `id`，讀取時從題庫取回內容；題庫更新後若某個 `id` 不存在，依「資料損毀」流程處理該局，`olympiad.record` 中不存在的 `id` 直接略過。
- 不使用 `olympiad.pregen`、`olympiad.recent`（見「共用規格的例外」）。

## 外觀

小朋友常一次玩很久，外觀以**長時間閱讀不疲勞**為優先，比共用規格的豐富色調更收斂：

### 護眼配色

- 遊戲主色：低彩度的**霧藍紫**漸層，淺色 `--brand-1: #5f6aa0`、`--brand-2: #4a527f`，深色 `--brand-1: #56608f`、`--brand-2: #3d4466`（HSL 飽和度約 25%）。白字在主色上的對比度至少 5:1。
- 主色只用在首頁橫幅、難度按鈕、頂部列與工具列；**作答區（題目、解題重點、選項、詳解）不使用漸層、主色或高彩度底色**。首頁橫幅背景可點綴淡色的數學符號（＋、×、π、△），作答畫面不放裝飾圖案。
- 背景與文字（不用純白底配純黑字，減少眩光）：

  | 用途 | 淺色 | 深色 |
  | --- | --- | --- |
  | 頁面與作答區背景 | `#f6f1e7`（米白） | `#23262b`（暖深灰，不用純黑） |
  | 選項按鈕背景 | `#fffdf8` | `#2d3137` |
  | 主要文字 | `#3b3a36`（對比度 10.1:1） | `#e4dfd4`（對比度 11.4:1） |
  | 次要文字（題號、耗時） | `#6b665c`（5.1:1） | `#a9a294`（6.0:1） |
  | 答對（✓） | 文字 `#2f6b3d`、底色 `#e3efe1`（5.4:1） | 文字 `#9fd0a8`、底色 `#2a3a2e`（6.9:1） |
  | 答錯（✕） | 文字 `#a2453c`、底色 `#f6e3df`（4.9:1） | 文字 `#f0a59b`、底色 `#3d2b29`（6.7:1） |

- 所有文字對比度介於 4.5:1 與 15:1 之間：足以看清楚，又不像純黑白那樣刺眼。
- 大面積色塊（超過畫面 1/4）的 HSL 飽和度不超過 30%；高彩度的顏色只用於答對、答錯的小面積標示。
- 深色模式依共用規格跟隨系統並可手動切換；晚上在交通工具上建議使用深色。

### 字體與版面

- 題目字級 20 CSS px、行高 1.7；選項與解題重點字級 18 CSS px、行高 1.6；頁面內文最小 16 CSS px。
- 題目區每行最多約 22 個中文字（手機直向自然達成；橫向或平板時限制內容寬度），避免視線長距離移動。
- 使用系統內建字型，不使用細體（字重至少 400）。

### 動態效果

- 答對、答錯的回饋為單次、200 毫秒以內的淡入，不閃爍、不晃動、不使用持續動畫；開啟「減少動態效果」時直接顯示。

### 休息提醒

- 連續遊玩累計 20 分鐘（以耗時計算，暫停與在背景的時間不算；跨局累計，回到首頁超過 5 分鐘則歸零）後，在答對一題、按「下一題」時顯示「休息一下吧！看看遠方 20 秒，讓眼睛放鬆」，提供「好，休息一下」（進入暫停畫面）與「繼續作答」。
- 每次提醒後重新累計；同一局最多提醒 3 次。可在首頁設定關閉（`olympiad.settings`），預設開啟。
- 不強制中斷、不鎖定畫面；提醒期間計時依暫停規則處理。

- 其餘依共用規格的豐富色調要求；上架時大廳卡片使用相同的霧藍紫漸層。

## 驗收條件

除共用驗收條件外：

1. 題庫與模板自動化檢查全部通過；固定題庫每個難度至少 100 題、8 種題型，題型模板每個難度至少 4 個；所有題目與模板都經獨立審題且有紀錄。
2. 答錯第 1、2、3 次分別顯示第 1 段解題重點、第 2 段解題重點、「只剩下一個選項」訊息；整個過程畫面上不出現正確答案，直到答對才顯示詳解。
3. 主動查看解題重點會扣額度，答錯自動顯示的不扣；額度用完時按鈕停用並說明。
4. 每題都必須答對才能進入下一題；完成畫面正確標示每題的作答結果。
5. 10 題都沒答錯、沒看解題重點時，`noHint` 累加並寫入 `perfect` 禮包；有答錯時只寫入 `clear`；同一難度再完成一次不重複寫入。
6. 錯題本：答錯或看過解題重點的題目進入「待複習」，之後一次答對即移出；「重設統計」不影響錯題本。
7. 連續開 10 局同一難度，固定題不重複；每局 6 題固定題、4 題模板題（模板足夠時），同一模板一局最多 1 題，同題型不超過 3 題；模板題答錯後，之後的局會優先以同一模板換數字出題。
8. 重新整理或在背景被系統結束後再開啟，題號、選項順序、已選過的選項、已顯示的解題重點、錯誤次數、提示餘額與耗時都與最後一次操作一致。
9. 手機直向 375 CSS px 寬可單手完成所有操作，題目與解題重點較長時選項仍在畫面內。
10. 護眼配色：淺色與深色模式的顏色符合「護眼配色」的表，作答區沒有漸層或高彩度底色；以對比度工具抽查文字對比介於 4.5:1 與 15:1 之間。
11. 休息提醒：累計遊玩 20 分鐘後在下一題前出現提醒，暫停與背景時間不計入；關閉設定後不再出現。
12. 大廳顯示「奧數挑戰」卡片（霧藍紫）、離線可玩、版本號、繼續遊戲與戰績（依「上架到大廳」驗證）。
