# 一般怪物新美術規格

本文件交給實作者（Codex），描述如何把 44 種一般怪物換成高解析度的動作圖。Boss 已經有新美術，不在範圍內。

開始前先讀：

- `/Users/matis/ebet/game-portal/AGENTS.md`
- `games/spec.md`
- `games/pocketdungeon/spec.md`
- `games/pocketdungeon/README.md`

## 1. 目標

- 一般怪物的精細度要接近角色與 Boss，畫風參考市面上的像素風手遊：
  - 深色外框；
  - 3～4 階明暗，左上受光；
  - 眼睛、牙齒、鱗片、裝甲等有細節；
  - Q 版比例，頭部與特徵誇張，一眼可辨識。
- 每種怪物要有 4 格動作，與 Boss 相同：
  1. 待機 A
  2. 待機 B
  3. 蓄力
  4. 出招
- 不改變遊戲行為：碰撞半徑 `r`、數值、AI 與預警範圍全部不動。

### 現況

- 怪物圖在 `src/js/pd/sprites.js` 的 `MONSTER_ART`，是約 12×13 的手寫像素圖，有 2 格。
- 繪製時由 `refineMonster` 做 Scale2x 放大、把外框變細並加上光影，成為 2 倍密度（density 2）的圖。
- 放大後只是邊緣比較圓滑，沒有新增細節，看起來明顯比角色粗糙。

## 2. 作法總覽

整套流程沿用 Boss 的管線：設計圖 → 轉換腳本 → 產生的資料檔 → `sprites.js` → `render.js`。

1. 使用者用 GPT 產生每種怪物的設計圖，放在 `design/monsters/<key>.png`。提示詞見第 3 節。
2. 擴充 `scripts/make-hero-sprites.mjs`，加上 `--monsters` 模式，輸出 `src/js/pd/monsterSprites.js`。
3. `sprites.js` 的 `monsterArt`：有新圖的怪物使用新圖，沒有的維持 `refineMonster`。這樣可以逐隻替換，不必一次到位。
4. `render.js` 依怪物狀態選擇 4 格動作中的一格。

## 3. 設計圖規格（給 GPT 的提示詞）

### 版面

- 版面與 `design/bosses/*.png` 相同，可以先打開 `design/bosses/golem.png` 參考：
  - 白底，橫向一列 4 格：待機 A、待機 B、蓄力、出招；
  - 上方是名稱標題，下方是編號文字；
  - 怪物一律面向右，全身入鏡，腳底對齊同一條水平線，每格之間留明顯的白色空隙；
  - 格內不要有文字、地面、陰影、背景，也不要有和身體分離的特效。
- 和身體分離的特效會出問題：轉換時每格只保留最大的連通區塊，分離的部分會被丟掉。
  - 刀光、火焰等特效必須和身體相連；
  - 如果不想要特效，就乾脆不畫。
- 尺寸建議 2172×724，與 Boss 相同。如果 GPT 輸出別的尺寸，在轉換參數裡調整 y 範圍即可。

### 提示詞範本

把 `<名稱>`、`<外觀描述>`、`<蓄力描述>`、`<出招描述>` 換成第 4 節表格的內容：

```
像素風手遊怪物設計圖，白色背景，一列 4 格同一隻怪物的動作，面向右，全身入鏡，腳底對齊同一條水平線：
① 待機 A ② 待機 B（呼吸起伏的微小差異）③ 蓄力：<蓄力描述> ④ 出招：<出招描述>。
怪物：<名稱>，<外觀描述>。
畫風：精緻的 16-bit 像素畫，深色外框、3～4 階明暗、左上方光源、Q 版比例，與附圖中的角色同一個畫風。
格子內不要文字、地面、陰影與分離的特效；上方放怪物名稱標題，下方放 ①～④ 編號。
```

### 附圖

產生時附上一張現有的角色或 Boss 設計圖（例如 `design/bosses/golem.png`），請 GPT 沿用同一個畫風。

### 原創要求

- 不得模仿任何既有遊戲的角色造型、名稱或配色。
- 上方範本中的「與附圖同一個畫風」只是指本專案自己的圖。

## 4. 怪物清單

### 尺寸級別

尺寸級別決定轉換時待機圖的高度（單位為圖像素，密度 2）。角色是 34，Boss 是 60。

| 級別 | 高度 | 適用 |
|---|---|---|
| 小 | 28 | `r` ≤ 0.34 |
| 中 | 34 | 0.35 ≤ `r` ≤ 0.42 |
| 大 | 40 | `r` ≥ 0.44 |
| 巨 | 46 | 只有雪怪：原本以 `scale: 1.3` 放大，換新圖後改由圖本身決定大小 |

飛行怪物的高度算到身體底部，腳底線就是身體底部。

### 動作原則

- **蓄力**對應遊戲中的預警時間，要看得出「準備出手」，例如：
  - 後仰
  - 舉起武器
  - 張口集氣
  - 身體縮起
- **出招**對應判定瞬間，動作要大，例如：
  - 前撲
  - 揮下
  - 張口噴出
  - 舉手施法

### 特殊情況

- **寒霜幽魂、怨靈、魅魔**：遊戲中仍套用 `MONSTER_ART` 的 `alpha`（半透明），新圖照常畫實心即可。
- **石像鬼、飛龍**：沉睡時遊戲以灰階濾鏡畫出，不需要另外畫石像版本。
- **熔岩蟲、沙蟲**：鑽地時不畫圖，只有土堆，不受影響。

## 5. 程式修改

### 5.1 轉換腳本

修改 `scripts/make-hero-sprites.mjs` 與 `scripts/hero-sprites/sheets.mjs`。

#### 新增 `MONSTER_SHEETS`

- 寫法比照 `BOSS_SHEETS`：
  - `file: '<key>.png'`
  - `auto: { n: 4, y: [上緣, 下緣] }`
  - `cells: {}`
  - `hole`
- 新增每隻怪物的目標高度欄位 `h`，依第 4 節的級別填 28、34、40 或 46。
- 只列出 `design/monsters/` 裡實際存在的檔案；也可以在執行時略過不存在的檔案並列出警告。

#### 新增 `--monsters` 模式

- 讀 `design/monsters/`，輸出 `src/js/pd/monsterSprites.js`，匯出 `MONSTER_SPRITES`。
- 資料格式與 `BOSS_SPRITES` 相同：`palette`、`w`、`h`、`foot`、`frames`（4 格，面向右）。
- `TARGET_H` 改用每隻的 `h`，Boss 仍是 60，角色仍是 34。
- `COLORS`（減色後的顏色數）：小型怪物可以降到 16～20，避免雜點；用 `--preview` 確認後決定。
- `NAMES` 補上 44 種怪物的中文名，從 `data.js` 的 `MONSTERS` 取得也可以。

#### 檔案開頭說明

產生的檔案開頭要有和 `bossSprites.js` 相同格式的說明：來源、格式，以及「由腳本產生，不要手動修改」。

#### `package.json`

新增 `"monsters": "node scripts/make-hero-sprites.mjs --monsters"`。

#### 驗證轉換結果

每一張圖都要用 `--preview` 輸出預覽圖檢查，確認：

- 4 格都完整；
- 沒有殘留白邊與白洞；
- 沒有遺失和身體分離的部位；
- 腳底對齊。

#### 環境

- 需要 puppeteer-core 與 Chrome，見 `HANDOFF.md`（本機檔案）的「驗證流程」。
- 執行前可以用 `npm i --no-save puppeteer-core`，或建立指向既有路徑的暫時 symlink，用完要移除。

### 5.2 `src/js/pd/sprites.js`

- 匯入 `MONSTER_SPRITES`。
- 新增 `monsterSpriteArt(type)`，寫法比照 `bossArt`，但沒有進化配色：一般怪物不會進化，`evolvedPalette` 只有 Boss 使用。
  - 回傳 `frames`、`flash`（閃白）、`density: 2`、`foot`、`poses: true`。
  - `alpha` 沿用 `MONSTER_ART[type].alpha`。
  - `scale` 固定為 1，大小已經由圖決定，雪怪不再乘 1.3。
- `monsterArt` 的選擇順序：
  1. Boss 使用 `bossArt`；
  2. 有 `MONSTER_SPRITES[type]` 的怪物使用 `monsterSpriteArt`；
  3. 其他維持 `refineMonster`。
- 檔案開頭的註解要一起更新。

## 7. 規範

- 每個函式前都要有繁體中文註解或 JSDoc，包括回呼與箭頭函式。
- 不使用 npm 執行期套件。puppeteer-core 只用於轉換腳本，以 `--no-save` 安裝。
- 不要 commit 以下檔案：
  - `dist/`、`site/`、`node_modules/`
  - `.certs/`、`*.pem`
  - `HANDOFF.md`（只留在本機）
- commit 訊息用繁體中文，不加任何 AI 署名。只在使用者要求時 commit。
- **同時進行的工作**：怪物與 Boss 的攻擊特效強化會在另一條線修改 `render.js`（`spawnFx`、`drawFx`、`drawProjectiles`、`drawTelegraphs`、`drawEffects`）與 `world.js`（`telegraph`、`effect`、`shoot`）。
  - 本規格只需要改 `render.js` 的 `drawEntities` 怪物段與 `bossPose`，以及 `world.js` 的 `shoot` 一行。
  - 開始前先 `git pull`，盡量只改上述範圍，避免衝突。
