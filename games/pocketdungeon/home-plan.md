# 口袋地城「家園」功能規劃

狀態：實作中（2026-11-07）。已完成階段 1～3 與全部 150 件家具與裝飾美術（含 14 種地板與牆面、8 種作物）；其餘見「開發順序」。實作後的規則會寫進 [`spec.md`](spec.md) 的「家園」章節，本文件保留設計理由與清單。

## 目標

玩家打怪、逛商店、在庭院採收取得材料與製作書，在自己的房子裡製作家具與裝飾並自由擺放；可以買地擴建房子與庭院，在庭院種果樹與藥草，收成後合成道具帶進地城。

設計原則：

- **延續學習動機**：家園不產出入場卷與獎勵禮包；在其他學習遊戲過關可得到肥料加速種植。
- **給探索理由**：每個區域掉落不同的家園材料與主題裝飾，玩家會想去各個地城。
- **不衝擊現有經濟**：每趟探險攜帶藥水的上限不變（回復 10、淨化 5），料理加成維持小幅度。
- **質感優先**：家園物件用比地城更高的解析度繪製（見「美術規格」）。
- **可分段上線**：每個開發階段完成後都能單獨遊玩。

## 玩法循環

1. 打怪、開寶箱、逛商店、到庭院採收 → 取得家園材料、家具製作書、種子。
2. 在家裡的工作台用製作書、材料與金幣做出家具與裝飾。
3. 進入佈置模式，把家具與裝飾擺進房子或庭院。
4. 存錢與材料買地擴建，房子與庭院變大。
5. 在庭院種果樹與藥草，收成後到藥草台合成藥水或料理，帶進下一趟探險。

## 家具製作書

與裝備用的「製作書」分開命名，避免混淆。

- 每本學會一個配方（家具或裝飾），學一次永久有效；重複取得的可以賣掉。
- 來源：打怪與寶箱掉落、商店每天陳列 2 本、Boss 掉落主題配方；獎勵禮包有機會開出。
- 依稀有度分四級：普通、精良、稀有、傳說（Boss 主題裝飾）。
- 製作需要已學會的配方、材料與金幣。
- 新角色預設會做木椅、木桌、木床、工作台、木地板、木牆 6 種，其他都要取得製作書。

## 美術規格（高解析度）

地城目前每格 16 像素、道具圖示約 6～14 像素。家園物件改用較高解析度：

- **家裡場景每格 32 像素**（地城的 2 倍），1×1 家具為 32×32，2×2 為 64×64，牆飾與小擺設約 16～24 像素。
- **介面圖示 48×48**（製作書、材料、配方圖鑑、佈置列）。
- **著色**：統一左上光源，每種顏色至少四階（陰影、基底、亮面、高光），外框用深色而非純黑，物件底部加柔和投影。
- **材質細節**：
  - 木頭：木紋與節點
  - 石頭：斑點與裂縫
  - 布料：織紋與縫線
  - 玻璃：反光斜線
  - 金屬：鏡面高光
  - 陶瓷：釉面光點
- **動態**：壁爐火焰、燭火、魚缸的魚、時鐘鐘擺、風車、噴水池、鞦韆、燈具光暈，2～4 幀循環。
- **作物**：每種作物三個生長階段，成熟時有閃光提示。
- **繪製方式**：
  - 新增 `homeArt.js`，以「部件」組合繪製：板材、圓柱、靠墊、葉叢、玻璃、金屬框等。
  - 每件物件用部件清單與調色盤描述，150 件物件不必逐點手寫，同一套光影規則也能維持一致質感。
  - 首次使用時畫到離屏 canvas 並快取。
- **審圖頁**：開發用頁面一次列出全部家具、裝飾與作物（含各動態幀與染色版），方便逐件檢查質感。

## 庭院種植

- **種子**：商店販售、打怪掉落；獎勵禮包有機會開出。
- **作物**：
  - 果樹：蘋果、橘子、葡萄。種一次可以重複收成。
  - 藥草：紅草、藍草、解毒草、星光花。收成一次後田地清空。
  - 棉花：收成後做成布料。
- **生長**：依實際時間，2～8 小時成熟，分三個階段。
- **肥料**：在其他學習遊戲過關時取得，可讓一塊田立刻長一階。
- **防止調時鐘**：記錄上次看到的時間；時鐘往回調時不倒扣、也不前進；單次最多計算 24 小時的生長。

## 牧場（2026-11-06 新增）

庭院除了種果樹與藥草，也可以養動物，定時收取產物。

| 動物 | 產物 | 週期 | 產物用途 |
| --- | --- | --- | --- |
| 雞 | 雞蛋 | 4 小時 | 料理（蛋餅、布丁） |
| 乳牛 | 牛奶 | 6 小時 | 料理（牛奶、起司、布丁） |
| 綿羊 | 羊毛 | 8 小時 | 做成布料 |
| 蜂箱 | 蜂蜜 | 6 小時 | 料理（蜂蜜蛋糕）、回復藥水的高級配方 |

- **欄位**：動物住在庭院的柵欄區，每隻佔 2×2 格；可養數量依土地等級（1、2、3、4、6 隻）。
- **照顧**：每天餵一次飼料（由庭院種的牧草或商店購買）才會產出；沒餵不會生病或死亡，只是暫停產出。
- **取得**：在商店購買幼崽；雞與蜂箱較便宜、乳牛與綿羊較貴且需要較高的土地等級。
- **防止調時鐘**：與作物相同。
- **肉的來源**：地城的野生怪物（野豬、蜥蜴人、飛龍等）掉落「獸肉」，用在料理；牧場動物只產出蛋、奶、毛、蜜，是一直陪伴的夥伴（使用者決定，2026-11-06）。

## 學科連動（2026-11-06 新增）

家園的動植物與學習遊戲的題目互相呼應：在學習遊戲學到的內容，回到家園可以「用得上」；在家園遇到的動植物，也會引導孩子回去學習。

**做法**：自然探險與社會科學都把收集到的知識卡存在 `science.cards`、`social.cards`（與口袋地城同一個網站，可以直接讀取，與現有的獎勵紀錄同一種做法）。

### 自然探險 → 牧場與作物

| 家園內容 | 對應的自然探險單元 | 解鎖條件 |
| --- | --- | --- |
| 雞、乳牛、綿羊 | 動物朋友（低年級）、動物的身體、生活與繁殖（中高年級）、生殖（國中） | 收集任一單元的科學卡 1 張 |
| 蜂箱 | 昆蟲世界（中高年級）、生態系（國中） | 同上 |
| 星光花、葡萄等較難的作物 | 植物朋友、植物的構造、繁殖與養分、生物體的營養 | 同上 |
| 料理（發酵、保存類，例如起司） | 微生物與食物保存 | 同上 |

- 每種動物與作物有一張「**觀察日記**」小卡，寫一個與單元相關、程度合適的小知識（例如雞蛋孵化需要的天數、植物需要陽光、水與空氣）。第一次收成時顯示，並提示「到自然探險練習『○○』單元可以學到更多」。
- 觀察日記的內容須與自然探險的科學卡一樣經過科學正確性審查，不自創有疑義的說法。

### 社會科學 → 臺灣特產與節慶裝飾

| 家園內容 | 對應的社會科學主題 | 例子 |
| --- | --- | --- |
| 臺灣特產作物 | 臺灣的地理（`tw-geo`）、產業與經濟地理（`economy-geo`） | 鳳梨、茶葉、稻米、芒果；收成時的小卡寫產地與氣候、地形的關係 |
| 節慶裝飾 | 家鄉與文化（`local`）、社會（`society`） | 春聯、端午香包、中秋燈籠 |
| 市集 | 經濟（`economy`） | 把多的作物與動物產物賣給村莊市集；價格依需求小幅浮動，說明「供給與需求」 |

- 解鎖條件同自然探險：收集對應主題的知識卡。
- 臺灣特產與節慶裝飾不計入家具 50 種、裝飾 100 種，另外列為「特產」與「節慶」圖鑑。

## 合成（藥草台）

| 產物 | 配方範例 | 作用 |
| --- | --- | --- |
| 回復藥水 | 紅草 ×2 | 與商店相同，可以省金幣 |
| 淨化藥水 | 解毒草 ×2 | 同上 |
| 果汁或料理 | 蘋果 ×3、橘子 ×2 等 | 下一趟探險的小幅加成 |
| 染料 | 星光花與其他作物 | 家具與裝飾改色 |

料理加成（初稿）：

- 種類：HP +10%、攻擊 +5%、移動 +5%、掉寶 +10%、經驗 +10%。
- 一次只能吃一種，只對下一趟探險有效，探險結束即失效。

## 畫面與操作

1. **家園分頁**（村莊 DOM 面板，新增在分頁列）：
   - 房子縮圖、土地等級、家園材料清單
   - 「回家」與「擴建」按鈕
   - 配方圖鑑：家具 50、裝飾 100 的收集進度；已學會的顯示圖示，未學會的顯示灰色剪影
2. **家裡場景**（canvas）：
   - 沿用 `dungeon.js` 的格子地圖與 `World` 的移動與碰撞，但沒有怪物。
   - 房子與庭院在同一張地圖上，以門相連；角色在家裡也以 2 倍解析度顯示。
   - 走到工作台、藥草台、寶箱或田地旁時出現「互動」按鈕；鍵盤沿用攻擊鍵互動。
3. **佈置模式**：
   - 點右上「佈置」進入，畫面顯示格線。
   - 從下方的家具列選一件，點格子放下；可以翻轉、移動、收回。
   - 不能放的格子顯示紅色。
4. **效能**：地板、牆面與靜止家具先畫成一張底圖，每幀只重畫角色與動態物件。

## 存檔

每個角色新增 `home` 欄位（每個角色各有一間房子），家園相關的資料都放在裡面：

```text
home: {
  level,                          // 土地等級 1～5
  mats: {},                       // 家園材料
  recipes: [],                    // 已學會的配方（家具與裝飾代碼）
  seeds: {}, produce: {},         // 種子與作物
  fertilizer,                     // 肥料
  inventory: {},                  // 做好但還沒擺放的家具與裝飾
  placed: [{ id, x, y, rot }],    // 已擺放的家具與裝飾（新家園預設放一張工作台）
  plots: [],                      // 田地（階段 6）
  chest: [],                      // 家用寶箱（階段 4）
  tiles: { floor, wall },         // 地板與牆面樣式
  lastSeen,                       // 防止調時鐘
  shop: { day, recipes }          // 今天商店陳列的家具製作書
}
```

之後的階段會再加上動物、料理加成（`meal`）與染色。

- **資料遷移**（`storage.js`）：舊角色自動取得等級 1 的家園、預設 6 種配方（木椅、木桌、木床、工作台、木地板、木牆）與 2 顆蘋果種子。
- **讀取修復**（`normalizeHome`）：未知的材料、配方、種子與家具移除，數量限制在上限內；擺放位置不合法的家具收回庫存，不讓角色因此無法讀取。
