# 單機數獨網頁版規格

## 產品範圍

- 製作可在手機及電腦瀏覽器遊玩的單機數獨，介面使用繁體中文，以手機直向操作為主要情境。
- 主要使用情境：個人在國外旅行、搭機或搭車等沒有網路或網路不穩的環境下打發時間；遊戲常被登機、轉乘、來電等事件中斷。
- 採標準 9 × 9 數獨：每列、每行及每個 3 × 3 宮格都須填入 1～9，且不能重複。
- 網站可安裝為 PWA。首次開啟須連網下載資源；成功載入一次後，即使離線也能重新開啟、繼續遊戲及產生新題目。
- 遊戲不需要帳號、後端、廣告或遊玩時的網路連線；不收集任何分析或追蹤資料。
- 不在本版範圍：多存檔槽位、多語系、雲端同步、每日挑戰、音效。
- 不限定前端框架或建置工具，但出題器與解題器須有自動化單元測試。

## 遊戲流程

1. 首頁可選擇「簡單」、「中等」、「困難」或「專家」開始新局；若有未完成的題目，可選擇繼續遊戲。首頁同時顯示離線就緒狀態及統計入口；與遊戲選單部署在同一網域時（選單於 localStorage `games.portal` 記錄其路徑），另顯示「‹ 所有遊戲」連結。
2. 開始新局時在裝置本機隨機產生題目與完整解答。每題必須只有一組解答；題目給定的數字不能修改。
3. 選取可編輯格後，可用畫面上的 1～9 數字鍵輸入或清除；桌面版也支援實體鍵盤數字鍵、Backspace／Delete／0 清除，以及方向鍵移動選取格；另提供快捷鍵：N 切換筆記、H 提示、P 或 Esc 暫停、Ctrl／⌘＋Z 復原，暫停時按 Enter 或空白鍵繼續。
4. 所有格子都填入正確數字後，停止計時並鎖定棋盤，顯示完成畫面，列出難度、耗時、錯誤次數與已用提示次數，若創下該難度最佳時間則一併標示，並提供再玩一局。完成後清除存檔，首頁不再顯示「繼續遊戲」。
5. 玩家可隨時離開並繼續同一局。同時只保存一局：開始任何難度的新局會覆蓋目前進度；若已操作過棋盤，須先確認。
6. 「重開本局」保留同一題目，清除所有玩家輸入、筆記與提示填入的格子，耗時、錯誤次數與提示額度一併重設為新局狀態；若已操作過棋盤，須先確認。
7. 不設錯誤次數上限，答錯不會結束遊戲。
8. 遊戲中按瀏覽器或系統的返回操作時，不得直接離開頁面或遺失進度：先回到首頁（進度已保存），在首頁再返回才離開。

## 棋盤與輸入回饋

- 清楚區分宮格邊界、題目給定數字、玩家輸入數字、提示填入數字及目前選取格。
- 選取格子時，以淡色高亮該格所在的列、行及宮格。
- 選取或填入一個已有數字的格子時，高亮棋盤上**目前可見且數值相同**的數字；不顯示未填格的解答。切換選取格時同步更新。
- 輸入與該格解答不同的數字時立即以紅色標示，並累計一次錯誤次數。錯誤數字留在棋盤上供玩家修改或清除，不自動改為正解，也不扣提示次數。
- 選取給定數字或提示填入的格子時不能覆寫或清除；未選取可編輯格時，數字鍵不修改棋盤。
- 錯誤除了紅字也應有文字或圖示說明，避免只靠顏色辨識。手機直向畫面應能完整顯示棋盤和主要操作，無水平捲動。
- 數字鍵上顯示該數字尚未正確填入的剩餘數量；某數字的 9 格都已正確填入時，該數字鍵以停用樣式呈現。
- 遊戲畫面持續顯示目前耗時（格式 `mm:ss`，超過 1 小時為 `h:mm:ss`）、難度及剩餘提示次數。

## 交通工具上的操作

- 單手操作：數字鍵、筆記、復原、提示等常用操作集中在畫面下方，手機直向時拇指可及；棋盤位於其上方。
- 防誤觸：
  - 停用雙擊放大與捏合縮放。
  - 停用 Android 下拉重新整理（overscroll）。
  - 停用長按選取文字、長按系統選單與點擊高亮閃爍。
  - 「開始新局」「重開本局」等會清除進度的操作須確認，且不放在數字鍵旁邊。
- 省電：
  - 不使用持續播放的動畫，介面轉場以短暫、單次為限。
  - 不要求螢幕常亮（不使用 Wake Lock）。
  - 出題與預先產生完成後，不在背景持續運算或計時輪詢；暫停或頁面在背景時停止所有計時器。
- 主題：預設跟隨系統的淺色／深色設定，並提供手動切換（淺色／深色／跟隨系統），適合夜間航班等昏暗環境；手動選擇保存在本機。
- 不播放任何聲音。

## 筆記與復原

- 提供「筆記」模式切換。筆記模式下按數字鍵會在選取的可編輯空格中切換該候選數字的小字標記，不視為答案、不檢查對錯、不計錯誤次數。
- 在格子填入正式數字時，清除該格所有筆記；清除正式數字後，不恢復先前的筆記。
- 不自動刪除同列、行、宮格中的筆記；筆記只由玩家手動維護。
- 提供「復原」，可依序撤銷輸入、清除及筆記變更。提示屬於已消耗的動作，不能復原；成功提示後清空先前的復原紀錄。
- 復原不扣回已累計的錯誤次數。復原紀錄不需在重新整理後保留。

## 暫停

- 提供暫停按鈕。暫停時停止計時並遮住棋盤內容，只顯示「繼續」操作，避免暫停期間觀察棋盤。
- 頁面切換到背景時自動進入暫停狀態；回到頁面時維持暫停畫面，由玩家按「繼續」恢復。

## 計時

- 耗時以「累計經過時間」計算：遊戲進行中以單調遞增的時鐘（例如 `performance.now()`）累加每段進行時間，暫停或進入背景時把該段時間加入累計值並存檔。
- 不得以「開始時刻與目前時刻的差」計算耗時。裝置時區變更、系統自動校時或手動改時間，都不得讓耗時跳動、變成負數或異常增加。

## 難度與出題

| 難度 | 每局提示額度 | 給定數字參考範圍 | 解題技巧要求 |
| --- | ---: | ---: | --- |
| 簡單 | 30 次 | 36～45 | 只用 Naked Single 與 Hidden Single 即可解完 |
| 中等 | 20 次 | 30～35 | 須至少使用一次 Pointing、Claiming、Naked Pair／Triple 或 Hidden Pair／Triple，且不需要更進階技巧 |
| 困難 | 10 次 | 24～29 | 須至少使用一次 X-Wing、Swordfish、XY-Wing 或 XYZ-Wing，且不需要更進階技巧 |
| 專家 | 5 次 | 22～27 | 須至少使用一次 Unique Rectangle、X-Chain、XY-Chain、Simple Coloring 或 W-Wing 等更進階技巧 |

- 所有難度都不得需要猜測或試錯（暴力回溯）才能解出；專家題若現有技巧集合無法解完則捨棄重新產生。
- 難度以「僅會指定技巧的邏輯解題器」判定：該解題器依由易到難的順序套用技巧，以解完全盤所需的最高技巧等級決定難度。給定數字數量僅作輔助篩選，不作為難度依據。
- 產生後須驗證唯一解（以完整回溯解題器計算解答數量，找到第 2 組即判定失敗）及難度；不符時重新產生。
- 出題在 Web Worker 中執行，出題期間主畫面不得卡住，並顯示載入狀態。
- Web Worker 無法建立或載入失敗時（例如未啟用 Service Worker 快取且已離線，抓不到 Worker 腳本），改在主程式以已載入的出題器出題，不得因此無法開新局。
- 效能目標：在中階手機上，簡單與中等 2 秒內、困難 5 秒內、專家 10 秒內完成出題。簡單至困難超過 15 秒、專家超過 30 秒視為逾時，停止本次出題並顯示失敗訊息與重試按鈕，不開始無效題目。
- 預先產生：開始一局後，於閒置時在 Web Worker 為「剛開始的難度」預先產生下一題並存在本機，完成後即停止運算；下次開始該難度時直接使用，達成立即開局。預先產生的題目使用後即刪除；若不存在或損毀，則即時出題。
- 隨機出題必須在離線環境運作。在本機保存最近 50 題的題目雜湊值，新題目不得與其中任何一題完全相同（經旋轉、鏡射或數字置換後才相同者不必排除）。

## 提示規則

- 提示額度屬於每一局，開始新局或重開本局時依難度重設；答錯不扣額度，也不限制繼續遊玩。
- 點選「提示」時：
  - 若目前選取的可編輯格尚未填對（空白或填錯），就填入該格正確數字。
  - 若目前選取的可編輯格已填對，提示不生效也不扣次數，並以短訊息說明「此格已正確」。
  - 若未選取格子，或選取的是給定數字／提示填入的格子，則從尚未填對的格子中隨機選一格提示，並將選取移到該格。
- 每次成功提示一格扣 1 次。提示可改正已填錯的數字，並清除該格筆記；提示填入的格子應有可辨識標記，之後鎖定不能修改或清除。
- 畫面顯示剩餘次數；用完後停用提示並說明原因，不要求連網或付費。
- 輸入、清除、提示及復原後，重新計算錯誤標示、相同數字高亮、數字鍵剩餘數量與完成狀態。

## 統計

- 每個難度分別記錄：已開始局數、完成局數、最佳時間、平均完成時間、未使用提示完成的局數。
- 只有完成的局計入時間統計；重開本局不算新的一局。
- 統計只存在本機，提供「重設統計」並須確認。統計資料損毀時重設為空白，不影響遊戲進行。

## 本機儲存

- 自動儲存題目、解答、難度、玩家輸入、筆記、提示取得的格子、已用提示次數、錯誤次數與已累計遊玩時間；重新整理或關閉瀏覽器後可恢復。資料只儲存在使用者裝置。
- 每次輸入、清除、筆記變更、提示、復原、暫停及進入背景時立即存檔；不得只依賴關閉頁面時觸發的事件（iOS 可能在背景直接結束頁面而不觸發）。
- 存檔資料包含格式版本號。讀取時若版本無法辨識或資料不完整，依「資料損毀」流程處理。
- 若本機進度資料損毀或遺失，顯示提示並允許開始新局，不讓畫面卡在無法操作的狀態。
- 已知限制：
  - iOS Safari 對未加入主畫面的網站，可能在 7 天未使用後清除本機資料。
  - iOS 的主畫面 App 與 Safari 分頁的資料互不相通；在 Safari 中的進度與統計不會帶到主畫面 App。
  - 於 iOS 瀏覽器（非主畫面 App）中開啟時，首頁應提示「加入主畫面」，並說明上述兩點。

## PWA 與離線

- 提供 PWA manifest 與圖示，以 Service Worker 快取執行遊戲所需的全部資源（HTML、JS、Web Worker 腳本、CSS、字型、圖示、manifest）。遊戲核心流程不得依賴外部 CDN、API 或遠端字型。
- 快取策略：遊戲資源一律「快取優先」，不得等待網路回應才顯示畫面；有網路時才在背景檢查新版本。網路緩慢、需要登入的公共 Wi-Fi（Captive Portal）或請求被導向其他網頁時，App 仍須立即以快取開啟。
- 離線就緒狀態：首頁顯示「✓ 已可離線使用」或「離線資源下載中」。須在 Service Worker 已啟用且所有必要資源都確認存在於快取後，才顯示「已可離線使用」。
- 版本更新：新的 Service Worker 須完整下載並快取新版所有資源後才可啟用；之前不得刪除舊版快取。下載完成後顯示「有新版本，重新整理以更新」提示，由玩家決定何時更新；不得在遊戲進行中強制重新載入。更新後須能讀取舊版存檔與統計，或依「資料損毀」流程處理。
- 開發模式預設不啟用 Service Worker 快取，或提供明確的清除快取方式，避免載入舊程式碼；驗證離線功能時才啟用。
- 與遊戲選單及其他遊戲部署在同一網域的不同目錄時（例如 `/sudoku/`），Service Worker 的 scope 與快取名稱互相獨立；離線就緒狀態與新版本提示一律以本遊戲自己註冊的 Service Worker 判定，不以目前控制頁面的 Service Worker（可能暫時是選單的）判定。
- 「出發前檢查」與安裝到主畫面的說明統一放在遊戲大廳，遊戲內不另外提供。

## 相容性與無障礙

- 目標裝置：作者本人的手機（iOS Safari／主畫面 App 或 Android Chrome 的最新版本）及桌面瀏覽器（Chrome 或 Safari 最新版本）。其他瀏覽器不保證支援。
- 版面：以手機直向為主；手機橫向與平板須可正常遊玩（棋盤與數字鍵可改為左右排列），不得出現水平捲動或操作被遮住。
- 觸控按鈕至少 44 × 44 CSS px。
- 建議（不列入驗收）：文字與錯誤標示的對比度符合 WCAG 2.1 AA；棋盤格子與按鈕提供螢幕閱讀器標籤（例如「第 3 列第 5 行，玩家輸入 7，錯誤」）。

## 部署與 HTTPS

- 正式網站隨遊戲大廳一起部署於 GitHub Pages（`game-portal-fly` repo），網址 `https://matishsiao.github.io/game-portal-fly/sudoku/`；由 GitHub 自動提供受信任憑證並續期，部署流程見 `games/spec.md`「部署與 HTTPS」。正式環境不得使用開發用自簽憑證。
- 建置產物為純靜態檔案，部署時不需要後端；`npm run build` 輸出到 `dist/`，由大廳的 `scripts/assemble.mjs` 組合到網站的 `sudoku/` 目錄。
- 手機測試以部署後的正式網址為主。
- 選用：區網 HTTPS 開發模式（若需要在部署前以手機透過區網測試 Service Worker）：
  - 提供開發用 HTTPS 啟動指令，以 mkcert 產生本機 CA 簽發的憑證；首次執行自動產生，之後重用有效憑證，過期或區網 IP 改變時重新產生。
  - 手機須安裝並信任該 CA。iOS 安裝描述檔後，須另到「設定 → 一般 → 關於本機 → 憑證信任設定」開啟完整信任；Android 於「設定 → 安全性 → 加密與憑證 → 安裝憑證 → CA 憑證」安裝（不同廠牌路徑可能不同）。
  - 憑證私鑰與本機 CA 私鑰不得提交至版本控制，存放於被忽略的本機目錄。

## 驗收條件

1. 四種難度各以出題器批次產生 100 題，全部通過唯一解檢查，且以邏輯解題器判定的難度等級與所選難度一致；離線狀態下也能產生可玩的題目。
2. 在中階手機上，出題時間符合效能目標，出題期間介面仍可回應；逾時或失敗時可重試。有預先產生的題目時，開始新局立即顯示棋盤。
3. 填錯立即顯示紅色並累計錯誤次數，改對後恢復正常；相同數字高亮只反映棋盤上已顯示的數字。
4. 簡單／中等／困難／專家每局分別有 30／20／10／5 次提示；只有成功提示才扣 1 次，答錯不扣，用完後不能再提示。提示填入的格子不能修改，也不能被復原。
5. 筆記可新增、移除，填入正式數字時清除該格筆記；復原可依序撤銷輸入、清除及筆記變更。
6. 暫停或切到背景時計時停止且棋盤被遮住；繼續後接續計時。遊戲中變更裝置時區或系統時間，耗時不跳動。
7. 重新整理、關閉後再開啟，或在背景被系統結束後再開啟，棋盤、筆記、難度、提示餘額、錯誤次數與耗時都與最後一次操作一致；完成時顯示結算畫面，且存檔被清除。
8. 重開本局後，題目不變，玩家輸入、筆記、提示格、耗時、錯誤次數與提示額度回到新局狀態。
9. 完成一局後，該難度的統計正確更新；破紀錄時完成畫面有標示。
10. 手機直向與橫向螢幕可單手完成選格、輸入、清除、筆記、復原、提示、暫停及開始新局，主要操作不被遮住；雙擊、捏合、下拉、長按不會造成縮放、重新整理或跳出選單；遊戲中按返回不會遺失進度。桌面可用鍵盤完成選格與輸入。
11. 出發前檢查：在主畫面 App 中確認「已可離線使用」後，開啟飛航模式並將手機重新開機，再開啟 App：可繼續原局、四種難度都能開始新局，中途切到背景再回來一切正常。
12. 連上尚未登入的 Captive Portal Wi-Fi 或極慢網路時，App 仍立即以快取開啟並可遊玩。
13. 部署新版後，進行中的遊戲不被強制中斷；新版資源未下載完成前斷網，App 仍以舊版正常運作；玩家同意更新後能讀回原進度與統計。
14. 未啟用 Service Worker 時，頁面已開啟的情況下斷網，仍可連續開始四種難度的新局。
